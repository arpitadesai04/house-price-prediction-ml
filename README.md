# 🏠 House Price Prediction Using Machine Learning

An end-to-end Machine Learning project that predicts house prices in Bengaluru using Python, Machine Learning, Pandas, Scikit-learn, Matplotlib, Seaborn, and Streamlit.

## 🚀 Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization using Matplotlib and Seaborn
- Multiple Machine Learning regression models
- Model evaluation using MAE, RMSE, and R² Score
- Interactive house price prediction web application using Streamlit

## 🛠️ Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Joblib
- Streamlit
- Jupyter Notebook

## 📊 Machine Learning Models
- Random Forest Regressor
- Extra Trees Regressor
- HistGradientBoosting Regressor

## 📁 Dataset
Bengaluru House Price Dataset from Kaggle.

## ▶️ How to Run

```bash
pip install -r requirements.txt
python train.py
streamlit run app.py
```

## 👩‍💻 Project Purpose
This project demonstrates an end-to-end Data Science workflow, from data preprocessing and exploratory analysis to model development and deployment.
